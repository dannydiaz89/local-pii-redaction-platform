# Security policy

## Supported versions

The project is pre-release. Until a first supported release is published, security fixes apply to
the current `main` branch only.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, bypasses, secrets, or sensitive test artifacts in a
public issue. Until the public repository enables GitHub private vulnerability reporting, use
[the dannydiaz89 GitHub profile](https://github.com/dannydiaz89) to request private contact
instructions without including vulnerability details in any public message.

Include the affected revision, impact, safe reproduction steps, and whether disclosure is already
public. Replace any real personal data with a synthetic reproducer. The maintainer will acknowledge
the report, coordinate validation and remediation, and provide disclosure guidance appropriate to
the severity.

No pre-release response-time SLA is promised. Good-faith reports that respect privacy and avoid
unnecessary access or disruption are welcome.
